# Pets Amigos

Site institucional fictício desenvolvido como projeto acadêmico de desenvolvimento web. O projeto simula a presença digital de uma organização de proteção animal, apresentando iniciativas de resgate, cuidados veterinários, adoção responsável, lar temporário e voluntariado.

## Sobre o projeto

O **Pets Amigos** foi criado com o objetivo de colocar em prática os conhecimentos adquiridos durante os estudos de desenvolvimento web, por meio da construção de um site institucional com páginas interligadas, organização semântica do conteúdo e recursos de acessibilidade.

O desenvolvimento acontece de forma incremental, acompanhando os conteúdos estudados e incorporando melhorias conforme o avanço do projeto.

## Objetivos de aprendizagem

- Aplicar HTML5 na estruturação semântica das páginas.
- Desenvolver layouts e estilos utilizando CSS3.
- Implementar recursos de acessibilidade e navegação por teclado.
- Organizar arquivos e utilizar Git e GitHub para versionamento.
- Validar a estrutura HTML e documentar as funcionalidades e limitações do projeto.

## Páginas do projeto

- **Início (`index.html`):** apresentação da organização fictícia e de suas propostas.
- **Projetos (`projetos.html`):** divulgação de iniciativas de proteção animal, incluindo resgate, cuidados veterinários, adoção, lar temporário, voluntariado e doações.
- **Cadastro (`cadastro.html`):** formulário destinado a pessoas interessadas em participar das iniciativas.

## Funcionalidades

- Navegação entre as páginas do site.
- Apresentação de projetos e ações de proteção animal.
- Divulgação de oportunidades de voluntariado e formas de apoio.
- Formulário com campos organizados por finalidade e validação nativa do HTML5.
- Recursos de acessibilidade, como textos alternativos para imagens, navegação por teclado e indicadores visuais de foco.

## Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub

## Validação e acessibilidade

Durante o desenvolvimento, são considerados os seguintes aspectos:

- Estrutura semântica e hierarquia dos títulos.
- Validação do HTML por meio do [W3C Markup Validation Service](https://validator.w3.org/).
- Verificação dos caminhos dos arquivos e do carregamento das imagens.
- Uso de atributos de acessibilidade e navegação por teclado.
- Organização dos arquivos e das pastas do projeto.

## Limitações atuais e melhorias futuras

O projeto está em desenvolvimento e, atualmente, utiliza HTML5 e CSS3.

O formulário conta com validação nativa para campos obrigatórios e formatos definidos no HTML. Entretanto, ainda não possui integração com backend ou banco de dados. Por isso, os dados preenchidos não são enviados a um servidor nem armazenados de forma permanente.

Também estão previstas possíveis melhorias, como:

- Implementação de layouts responsivos.
- Aprimoramento da experiência visual e da acessibilidade.
- Criação de máscaras para campos como CPF, telefone e CEP.
- Adição de funcionalidades interativas com JavaScript.
- Desenvolvimento de uma estrutura de backend para processamento e armazenamento dos dados.

Essas melhorias poderão ser incorporadas conforme a evolução dos estudos e dos requisitos do projeto.

## Uso de inteligência artificial

Durante o desenvolvimento deste projeto, ferramentas de inteligência artificial foram utilizadas como apoio na elaboração e no aprimoramento de textos e na criação das imagens utilizadas no site.

Os conteúdos gerados foram incorporados como recursos auxiliares ao desenvolvimento acadêmico, sendo o projeto organizado e desenvolvido de forma incremental durante os estudos.

As imagens que continham marcas-d'água foram mantidas com o objetivo de preservar os créditos e a identificação de suas respectivas fontes, sem a remoção dessas identificações.

O uso dessas ferramentas é declarado por transparência, reconhecendo a inteligência artificial como parte dos recursos utilizados no processo de desenvolvimento.

## Aviso

O Pets Amigos é uma organização fictícia, criada exclusivamente para fins educacionais. As informações, iniciativas e atividades apresentadas no site não representam uma instituição real.
